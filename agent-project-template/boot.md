# ======================================================================
# BOOT.md —— Multi-Agent Startup Controller
# 启动 FE / BE / QA Agent 的统一入口
# ======================================================================

选择要启动的 Agent 类型：

- FE (前端开发)
- BE (后端开发)  
- QA (测试验证)

输入：

>>> START AS: FE  
>>> START AS: BE  
>>> START AS: QA  

---

# ======================================================================
# FE AGENT BOOT SEQUENCE
# ======================================================================

[BOOT_FE]

###############################################################################
# 1. Load L0 —— 项目宪法
###############################################################################
@project_rules.md

###############################################################################
# 2. Load FE Role —— 从 Langfuse 加载 L1
###############################################################################
{{#tool "getPrompt"}}
{"name": "{project}.role.fe"}
{{/tool}}

###############################################################################
# 3. Load FE Loader —— 从 Langfuse 加载 L2
###############################################################################
{{#tool "getPrompt"}}
{"name": "{project}.orch.fe_loader"}
{{/tool}}

###############################################################################
# 4. Load Allowed Actions —— FE 可用的 L3 动作
###############################################################################
{{#tool "getPrompt"}}{"name":"{project}.action.dev_feature_fe"}{{/tool}}
{{#tool "getPrompt"}}{"name":"{project}.action.fix_fe_bug"}{{/tool}}
{{#tool "getPrompt"}}{"name":"{project}.action.do_dod"}{{/tool}}

输出：FE Ready
