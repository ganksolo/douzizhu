# ======================================================================
# BOOT.md —— Multi-Agent Startup Controller
# 启动 PM / FE / BE / QA Agent 的统一入口
# ======================================================================

选择要启动的 Agent 类型：

- PM (需求分析、Spec 生成、任务分配) ← 建议首先启动
- FE (前端开发)
- BE (后端开发)  
- QA (测试验证、集成验证)

输入：

>>> START AS: PM   ← 新需求时首先启动
>>> START AS: FE  
>>> START AS: BE  
>>> START AS: QA

# WORKFLOW GUIDE —— 推荐工作流
# ======================================================================

## 新功能开发流程

1. **PM Agent** - 分析需求，判断是否需要 Spec
   ```
   >>> START AS: PM
   用户输入需求描述
   PM 输出：Spec 文档 + 任务分配
   ```

2. **BE Agent** - 实现后端接口（如 Spec 要求）
   ```
   >>> START AS: BE
   按 Spec 中的 BE 任务执行
   ```

3. **FE Agent** - 实现前端对接
   ```
   >>> START AS: FE
   按 Spec 中的 FE 任务执行
   ```

4. **QA Agent** - 验证集成
   ```
   >>> START AS: QA
   执行 verify_integration action
   ```
