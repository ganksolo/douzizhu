# ======================================================================
# BOOT.md —— Three-in-One Agent Startup
# 启动 FE / BE / QA Agent 的统一入口
# ======================================================================

你现在需要选择要启动的 Agent 类型。  
可选值：

- FE
- BE
- QA

请在下方输入：

>>> START AS: FE  
或  
>>> START AS: BE  
或  
>>> START AS: QA  

输入后我会自动根据你的选择加载对应的 L0 / L1 / L2 / L3。
